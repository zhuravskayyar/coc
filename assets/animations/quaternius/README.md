# Archer locomotion source

Universal Animation Library, Standard edition, v3 (2026-06-16).
Author: Quaternius, with animation work by Gonzalo Furnier.
Official source: https://quaternius.itch.io/universal-animation-library
License: CC0 1.0; the original license is included in `LICENSE.txt`.

`UAL1_Standard.glb` is the original in-place source; `UAL1_Standard_RM.glb`
is the original root-motion reference used to evaluate travel and foot contact.
Both files were downloaded from the author's free Standard package.

The archer uses `Walk_Loop` and `Jog_Fwd_Loop`, fitted to her existing skeleton.
`Walk_Formal_Loop` and `Sprint_Loop` were evaluated but not selected.
The previous procedural walk is not used as a source.
