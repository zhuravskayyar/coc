# GitHub → локальна гра

Репозиторій: https://github.com/zhuravskayyar/coc. Основна гілка — `main`.

## Як працювати

1. Змінюй проєкт у браузері та зберігай зміни комітами в GitHub. Якщо робота йде в іншій гілці або через pull request, об'єднай її з `main`.
2. У локальній папці `coc` двічі натисни **Start-GitHub-Sync.cmd**. Синхронізація працює у фоні та перевіряє `main` кожні 60 секунд. Вікно з повідомленням можна закрити — фоновий процес продовжить роботу.
3. **GitHub-Sync-Status.cmd** покаже стан і останні повідомлення. `Updated` означає, що нові файли вже підтягнулися; `Up to date` — що локальна версія збігається з GitHub.
4. Відкрий `project.godot` у Godot, дай редактору завершити імпорт змінених ресурсів і запусти гру через **F5**. Якщо гра вже запущена, зупини її та запусти знову після синхронізації.
5. **Stop-GitHub-Sync.cmd** зупиняє синхронізацію. Після перезавантаження Windows її потрібно знову запустити через **Start-GitHub-Sync.cmd**.

## Захист локальних правок

Синхронізація лише завантажує зміни з GitHub. Вона не завантажує локальні файли на GitHub, не видаляє локальні правки й не переписує історію комітів.

Якщо з'явилися локальні зміни, нові файли, власні коміти або відкрита інша гілка, у стані буде `Paused`. Для відновлення повернись до `main` і збережи локальну роботу комітом та узгодь її з GitHub або тимчасово сховай через `git stash push -u`. Не застосовуй `reset --hard` для відновлення синхронізації, якщо є незбережена робота.

Якщо зник інтернет або GitHub недоступний, процес повторить спробу в наступному циклі. Git має бути встановлений, а доступ до репозиторію — налаштований на цьому комп'ютері.

Стан і журнал лежать у `.git/github-sync/`, тому не потрапляють у репозиторій. Кеш Godot `.godot/`, кеш Python та резервні копії Blender також не завантажуються.

## Команди для термінала

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\github_sync.ps1 -Action Start
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\github_sync.ps1 -Action Status
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\github_sync.ps1 -Action Stop
```

Для одноразового оновлення спочатку зупини фонову синхронізацію та виконай той самий скрипт із `-Action Once`.
